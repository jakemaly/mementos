# Mementos

This context describes the public web experience for Mementos and the people and data it serves.

## Public web experience

**Hosted public app**:
The Mementos installation operated by the project owner and reached through a web browser.
_Avoid_: self-hosted app when referring to this installation.

**Public shared demo**:
An unauthenticated hosted experience where visitors query a project-owned corpus and cannot write personal data into it.
_Avoid_: multi-tenant service, personal workspace.

**Visitor**:
A person using the public shared demo without an account or private workspace.
_Avoid_: customer, tenant, member.

**Curated corpus**:
The project-owned, read-only collection of sources exposed to visitors through the public shared demo.
_Avoid_: shared user data, public workspace.
