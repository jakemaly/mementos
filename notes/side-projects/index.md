# Side Projects

Personal and open-source projects organized by status:

- [[side-projects/active/index]] — Projects currently being built
- [[side-projects/ideas/index]] — Parked ideas, not yet started

When an idea becomes active, move it from `ideas/` to `active/`.
When completed, delete it — or move it to `archive/` if you want to keep the record.
(Subdomain archives like `notes/side-projects/archive/` can be added as needed.)
